# 拼好字：非根部取前两笔纠错与8177字记录

## 本次纠错

**撤回 `dd3ae1b` 中“首实笔之后继续寻找内部根”的规则及其改码结论。** 前轮把白取丿日、先／告取丿土，并用端接、不穿透等几何理由放行，是跳过了起首根资格；还将错误分支写进skill。这不是用户新裁决，已经纠正。

现行分支恢复为：

1. 先确定两个完整部分，各最多两码，不递归分部。
2. 整部分是现有根，直接取根；起首本来就是合法完整根，才可接直接后根或余部第一笔，如相取木丨、古取十口。
3. **起首部件不是根，该部只取真实前两笔，到此停止认根。** 禾、白、先、告、主、千、壬、干等非根部不能先取一笔再深入抽木、日、土、王、十、士。实笔有键位不等于获得继续认根的资格。
4. 码选定以后，才按对应单位在整字中的真实起笔位置输出；交错规则不授权额外抽根，也不把作为一部的式、匡复制成整字拆法。

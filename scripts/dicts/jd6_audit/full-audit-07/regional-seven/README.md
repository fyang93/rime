# 七字地区字形及笔序复核

## 判定范围

本轮只复查筥、簠、耰、艿、芈、苡、苣，不改维护表或skill。优先查地区限定的原页面和实际字图，不使用Rime多数票。汉典是第三方字典站，**不是官方规范发布机关**；“大陆版”在此特指其 `kai/cn` 字图及同字条正文笔顺，并不冒称拿到了大陆官方笔顺原表。

七字的汉典大陆版均可消歧，所得形码与现码一致；七字也均已取得台湾CNS官方正文的完整“筆順序”字段和官方字形，地区差异得到直接来源支持，不再仅是Rime来源冲突。主审核表的这七条只作**大陆版一致的地区限定结论**，另列台湾CNS版的独立码；不宣称全球同形同序，也不要求维护表迁就另一地区笔序。香港目前只有汉典标注的静态字形，未取得香港规范笔序，不反推其码。

## 版本保留原则

1. 筥的吕/呂、苡的四/五笔以、苣的四/五笔巨不是简单“票数不同”。保留可见字形及源序列，不将异形强判成同一错误笔顺。
2. 先前不能仅凭Rime文件头把主码称为CNS标准；本次实际取得CNS字段后，簠的13、耰的3、艿的35、芈的2112等才有了直接官方地区依据。七个Rime主序列的对应关系可追溯，但裁定依据是原站正文和实际字图，不是相符票数。
3. 本地MakeMeAHanzi芈行6251起横的轮廓/顺序，既不同于本次汉典大陆2121，也不能凭同字Unicode强归到CNS2112；继续保留为来源未定版本，不应用该笔序定本表现码。原版JD6丨一一一同样不冒充任何地区官方笔序。
4. 地区版本之间不同不自动判维护表错误。若以后采用非大陆字形，须按该版本的已核笔序单独重算，不能复制本轮大陆版的根资格或单位。7字目前已完成地区限定消歧；这不表示香港笔序、MakeMeAHanzi芈及一切其他历史版本都已得到裁定。

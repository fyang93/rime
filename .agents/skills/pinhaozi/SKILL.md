# 拼好字拆字

## 操作步骤

1. **确认范围和现状。** 读取 `scripts/dicts/chaizi_phz.txt` 中目标字及当前状态；补码目标是常用字表 `scripts/dicts/phz_targets.txt`（8253 字）；其余生僻字保持纯音，只在用户明确要求时扩展。分部与笔顺以原版 `scripts/dicts/chaizi_jd6.txt` 为首要参考：原版大部分拆分是对的（如者十日、猪丿乛十、萤草丨乛、劳草乛丿），每个字先看原版，原版符合本 skill 就直接采纳，不符合才改，并在依据里写明改的原因；旧表 `chaizi_jd6_v2.txt` 按旧规则拆分，不作参考。
2. **核字形。** 先确认目标字的实际字形、可书写主结构和笔顺。IDS只用于结构线索，不代表笔顺；异体、交叠或罕字用字形/笔顺资料交叉核对。要求“全部审核”时，每字实际看图并先记录独立分部、部码及证据，再与旧码比较；核对完整字集、图页读取和判码来源。候选检索、读取图页或格式测试均不能单独代替逐字判断；未检查与查过仍待裁须分开统计。
3. **先分两部，再按笔顺输出。** 合体字固定分两个完整部分：左右取左／右，上下取上／下，三列取左列／其余整体，完整上盖与下部两分。每部最多两码，部内按起首字根或笔画取码，不递归分部；整字为固定根则单取该根。每部最多取两个码：起首是字根时，先取该根；只有紧接其后的部件也是字根时才取第二根（中间隔着非根笔画就不取，不能跳过笔画去抽后面的根），第二根必须是真正的字根，单笔不算第二根，部内起首是根就不再取笔画（但人日、呓口草、压一丿土、㙦人土；旦整字是日／一两部，取日一）；部内不以余部笔画补码。起首不是字根时，按天然笔顺取前两个单位：单笔取笔画；紧接的部件若是独立、不与周围笔画相连的完整字根，则整取该根。如或部取一口；白中日形与撇相连，不是独立根，白部取丿丨，不能取丿日。取码顺序必须符合天然笔顺：只有两部分先后写完（一部写完再写另一部）才拆两部，码按第一部、第二部顺序输出；两部取完就结束，不满四码也不补码（俗人丿丶、浴水丿丶、谷丿丶口）；部件书写穿插的字（如式、匡、国、巫、丹、咸、囚）不拆两部。不能分成先后写完的两部分的字（部件穿插书写的字和独体字），整字按书写顺序取前四个单位：另起的独立部件是字根（完整写出、没有被其他笔画穿过、也不和其他部分共用笔画）就取根，否则取笔画。不可再分的单个部件（如白、告上部𠂒、王、午）内一旦开始取笔画，就一直取笔画，不在其中取由笔画凑成的根形（白丿丨乛一不取丿日，告上部丿一不取丿土）；但真实的、另起的子部件是根时照取根（咸一丿一口、囚丨乛人一）。如咸一丿一口、囚丨乛人一、巫一丨人人（口、人都是框内另起的部件）；白是一个部件，取丿丨乛一；本的木被末横穿过、果的日与木共用竖，都取笔画。用湘、鸿、营、寒等校准例确定分部；不为保旧码另造分法。用户明确指定的整字例外单列，不推广为新通则；龠按人／其余整体指定取人一口口，第二部的一口口是本字的三单位例外。查完 skill 仍不清楚、或发现未声明例外的条目互相冲突时，不要自行裁定，也不要只标存疑，先问用户。
4. **核对结果并同步。** 更新总表的拆码、状态和简短依据，同步逐字审核记录；重建索引与词库，运行校验和回归测试。

## 取码决策树

```text
字形、笔顺是否确定？
├─ 否 → 先查 skill，仍不确定就问用户
└─ 是 → 整字本身就是固定字根吗？
   ├─ 是 → 直接取一个字根，不补码
   └─ 否 → 能分成先后写完的两个完整部分吗？（部件穿插书写的不能分）
       ├─ 否 → 整字按书写顺序取前四个单位：另起的独立部件是完整、未被穿过、
       │       不共用笔画的字根就取根，否则取笔画；不可再分的部件内开始取笔画后不再取根；
       │       不足四个取实际个数
       │       （如戈→一乛丿丶、丁→一丨、式→一一丨一、咸→一丿一口、囚→丨乛人一、
       │        巫→一丨人人、白→丿丨乛一、本→一丨丿丶）
       └─ 是 → 分别处理两部分（每部最多两键，不递归分部），按第一部、第二部顺序输出
           ├─ 整部分就是一个现有字根 → 只取该根
           ├─ 起笔是根，紧接其后又是一个根 → 按序取两根
           │  （如吅→口口，吉→士口；隔着非根笔画的不取，如者的耂部只取十；
           │   部内只有一个根时部内不补）
           ├─ 起首部件不是根 → 按笔顺取前两个单位；紧接的独立完整字根整取，不与周围笔画相连才算
           │  （或部→一口、匽部→一日；白中日不独立，白部→丿丨；禾部、先部、告部→丿一）
           └─ 两部取完即结束，不满四码也不补（如何→人一口、河→水一口、俗→人丿丶）
```

- **先判根的独立资格，再顺取两个单位。** 非根部件起首取实笔；随后紧接的完整字根若独立、不与周围笔画相连，则整取该根，不机械截成第二条实笔。或、可、叵部取一口，匽部取一日，哥取一口一口；白中日形与首撇相连，不是独立根，白部仍取丿丨。禾、先、告、主、干同样不能从连写的单部件中凑木、土、十等根。不能越过中间笔画找后根，也不能另造“首笔／剩余根”主界。起首是根时，只有紧接的第二个部件也是真字根才取第二根；单笔不算第二根，部内不补余笔。
- 只有已取得合法根资格，才核完整性与起笔次序。完整根的末笔被插写不自动否定根。部件穿插书写的字和独体字一样整字按书写顺序取单位，不另造分部，也不交错输出。端接或不穿透也不能代替起首根资格。
- 两部独立限额，各最多两键，部内不互借名额；两部取完即结束，不补码。班按左王／中间两笔及右王取一一、丶丿；斑按王／文王取一一、丶一；楙按木／矛木取木、乛丶。彬按林／彡取木木、丿丿。
- 字根限下表；讠、纟等按既有前两笔处理，不临时增加“言、丝”等根。熟悉的部件名不等于现行字根。
- 不把父部件与子部件重复计码，不将难拆块递归展开成全部笔画；田、里不能抽取内部日形。
- 包围、半包围结构的外框若在内件之后才封口或续写（如国、匡、区、式、咸、囚、困、回），属部件穿插，整字按书写顺序取单位：内件是完整、未被穿过的字根就取根（咸一丿一口、囚丨乛人一、困丨乛木一、回丨乛口一、匼一人一口），不是根就取笔画（国丨乛一一、威一丿一乛）；外框先写完再写内件的（如内）才两分。被穿过的不算根：内、肉上部的人撇穿出框，取丿丶；夹的人被横穿过，取笔画。戴、𬸘等已有用户明确裁决的字按其裁值。
- 可整字依书写顺序取一口丨；作为另一字的一部时，起首非根，前两个单位是一、口根，取一口，如河为水一口、何为人一口。
- 耂中土形被撇穿透，不取土；起首取十。十后紧接的是横、撇，不是根，耂部只取十。如者为耂／日取十日，老为十丿乛，考为十一乛，猪为丿乛十。
- 凡艹下紧接冖的字（营、萤、荣、劳、蒙、荤、蒄、蓂等），一律把艹冖作为完整上部，再与下部两分；上部只取草，不补冖的首点，也不把冖另拆成第三大部。如营草口口、萤草丨乛、荣草木、劳草乛丿、荤草一乛（车：横、撇折、横、竖）、蒙草一一。这类字作为另一字的第二部时（如嵘、崂），第二部起首是草根，只取草，如嵘为丨乛草。
- 贲作为完整一部起首取十、紧接独立艹，部码十草；偾人十草、愤丶丶十草、喷口十草、豮一丿十草、鲼丿乛十草、𣸣水十草。整字贲保持卉／贝两部，取十草／丨乛。啬起首按用户确认取十，不取土；墙土十、嫱乛丿十、樯木十、穑丿一十、蔷草十。截、栽穿插整取时起首十根有效；斗的十与两点不相连，取丶丶十；犀中独立氺取水，尸／氺牛取乛一水。
- 用已确认例字类推：行夹字按彳／其余整体，参照衍、衒、衔；衣夹字参照亵、衮；人盖字参照余；上下复合主体参照寒。湘按氵／相取水木，鸿按氵／工鸟取水一丨，优先于旧版江／鸟的分法。字形、分部、根独立性或笔顺拿不准时，先看原版 JD6，再查本 skill，仍不确定才问用户。

## 唯一字根表

**只有用户指定的字根及明确指定的对应形才是字根；其他近形一律不算。** 本表之外的任何部件、偏旁、部首或整字，不能因形近、名称、字源、部件含义或 IDS 归类并入字根。朩按原版 JD6 算作木：条、杂、杀、亲、茶的下部都取木，如茶取草人木、条取丿乛木；余、荼、涂、途、斜的下部是一＋小，不是朩，按笔画取。言不是根：言整字按独体取前四笔丶一一一（同原版 JD6）；作为其他字的完整一部时取前两笔丶一。

当前唯一认可的17组字根是（5个笔画＋12个字根）：

```text
一  丨  丿  丶  乛
日  月  金  木  水  火  土/士  人  手  口  十  艹
```

只用以上17组，不自行增加根。总表规范写作草、手、金、水、人；其中草是艹的码名，不是把整个草字当成艹根；廿／龷顶部的连续一丨丨不独立取草，昔、堇等按实际起笔笔画处理；草字应按艹／早取草日十。实际字形是士/土时可保留对应写法。水组按原版 JD6 包括氵、水和氺（如录、黎的下部），都取水。曰算作日（昌日日、倡人日日、曼日丨乛，同原版）。日的o/e、丿的p/s都是同一单位的两个形码别名；s只为按键顺手，拆码总表仍记丿。

| 根 | 键 | 根 | 键 |
|---|---|---|---|
| 一 | a | 丨 | l |
| 丿 | p/s | 丶 | d |
| 乛 | v | 日 | o/e |
| 月 | y | 金 | j |
| 木 | m | 水 | u |
| 火 | h | 土/士 | t |
| 人 | r | 手 | f |
| 口 | k | 十 | x |
| 艹 | c | — | — |

表外部件作为一部时顺取前两个单位，紧接的独立完整字根可整取，否则取实笔；整字按书写顺序取前四个单位。常见的：目丨乛（目不是日根，田、里也不抽日）、隹以亻起首取人、足以口起首取口、讠丶乛、纟乛乛、王一一、工一丨、女乛丿、竹及⺮丿一、犭丿乛、豸丿丶、虫／山／贝丨乛；火根只认实际火形，灬不是火，取丶丶；宀、穴、阝、辶同样按实际笔画。

分部和笔顺可参考原版 JD6 表 `scripts/dicts/chaizi_jd6.txt`：它比上表多一个贝（这里按丨乛）、少一个火。取码以本 skill 和用户裁决为准。原版的常见偏差：多贝、少火、重复末根或补笔补满四码（本表两部取完即停，不补）、“未知”项，以及少数字把部内余笔补进码（如雠作人丶丶乛，本表为人丶乛）。

## 证据与不确定项

- 记录取码分支和最终单位：起首根合法时才列紧接其后的第二根；起首非根时记录前两个实际单位及依据；第二单位若为字根，须说明其独立、不与周围笔画相连，不能从连写单部件中凑根。保留完整结构，不把父部件和子部件重叠计入。
- 合体字明确记录两个完整部分、每部的一至两码和必要的笔顺证据；不能把三块顺取塞进“独体”或“裁决”规避两部限额。独体、整字根和仍有效的指定特例单列说明。IDS、读音、语义、旧码、码表字母串都不能单独证明拆法。
- 查证后仍不能确定字形、分部、根独立性或笔顺时，先查本 skill；仍不能确定就问用户，得到答复后再定码，不自行裁定、不编造形码。上述校准表中的最新用户分部确认优先于历史报告；未获新裁定的其他层界仍保留未决，不把本轮个别字例推广成新通则。遇多条完整层界，先读 `scripts/dicts/jd6_audit.md` 的用户确认分部表；原19项已全部定案，不再悬置，也不把个别分部推广为新通则；不临时创建“三层字一律顶盖优先”，不将旧审核者的结论转述成用户特裁。
